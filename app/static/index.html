The Model

Categorical features were one-hot encoded and numerical features prepared for modeling. Multiple regressors were evaluated using 5-fold cross-validation with MAE, including Ridge, Random Forest, Gradient Boosting, XGBoost, and LightGBM, with and without a log-transformed target.

The selected RandomForestRegressor was tuned and trained to predict customer purchase amount.

diwali_spend_model.pkl

Exploratory Data Analysis

The analysis revealed clear patterns across customer demographics and purchasing behavior. Women accounted for the majority of orders, with ages 26–35 forming a prominent customer group. Uttar Pradesh, Maharashtra, and Karnataka stood out across states, while IT, Healthcare, and Aviation were prominent occupations. Food, Clothing, and Electronics were among the leading product categories.

What the Data Reveals

The analysis identifies married women aged 26–35 in Uttar Pradesh, Maharashtra, and Karnataka, particularly those working in IT, Healthcare, and Aviation, as the highest-spending customer segment in this dataset.

The prediction layer uses the trained Random Forest regression pipeline to estimate purchase amounts from the selected customer attributes. The result is not just a prediction — it is a complete path from raw transaction data → exploratory analysis → feature engineering → model selection → prediction.

Every insight shown here comes from the underlying data and trained model. The interface visualizes and exposes those findings; it does not invent them.
